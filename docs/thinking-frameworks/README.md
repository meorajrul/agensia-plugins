# Neutral harness design checks

The four self-contained checks cover scope coverage, decision risk and frequency, reversibility, and responsibility. They use general wording without corporate sources, endorsements or historical-origin claims. They replace the previous externally attributed reference cards rather than presenting those cards as unattributed originals.

Edit `frameworks.json` or `skill-map.json`, then run `python3 scripts/thinking_frameworks.py`. Generated skill sections and references must not be edited directly. Regenerate the catalog and validate after changes.
